# Contributing

Thanks for helping out.

1. Create a new branch from `main`.
2. Put your changes in the right dimension: `universes/`, `platforms/`, `environments/`, or `civilizations/`. Code used by more than one dimension goes in `shared/`.
3. Never commit secrets. Use `.env.example` to document new variables.
4. Open a pull request with a short description of what changed and why.

By contributing, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
